# Credisnet v4 — sitio nuevo desde cero (SOLO PARA PRUEBA)

Sitio estático en `docs/` para GitHub Pages. El workflow de Pages prepara una vista no indexable para prueba.
No es producción. No subas esto al sitio de producción sin aprobación.

## Publicar en prueba
Subir el contenido de esta carpeta a un repo nuevo de GitHub, rama `main`, y activar GitHub Pages.
El workflow `.github/workflows/pages.yml` valida, prepara la vista no indexable y publica.
